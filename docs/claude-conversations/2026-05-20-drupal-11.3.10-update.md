# Drupal 11.3.9 → 11.3.10 — twig audit ignores removed — 2026-05-20

Patch release within 11.3.x. The key win: **drupal/core 11.3.10 widens the twig constraint** so composer can pick a non-advisory twig version. The ten `audit.ignore` entries added to `composer.json` for the previous (11.3.9) update have been removed.

## What changed

| Package | Was | Now |
|---|---|---|
| drupal/core (+ -recommended, -composer-scaffold, -project-message) | 11.3.9 | **11.3.10** |
| twig/twig (transitive) | 3.22.2 | **3.26.0** |
| symfony/deprecation-contracts | 3.6.0 | 3.7.0 |
| symfony/event-dispatcher-contracts | 3.6.0 | 3.7.0 |
| symfony/service-contracts | 3.6.1 | 3.7.0 |
| symfony/translation-contracts | 3.6.1 | 3.7.0 |
| symfony/polyfill-* (six of them) | 1.33.0 | 1.37.0 |

No contrib module updates this round.

## composer.json change

Removed the entire `config.audit.ignore` block that was added 24 hours ago for the twig 3.22.x advisories. Twig is now on 3.26.0 (clean), so the ignores are no longer needed.

```diff
   "config": {
     ...
-    "sort-packages": true,
-    "audit": {
-      "ignore": {
-        "PKSA-5k7f-wvjj-jrgw": "twig/twig 3.22.x — ...",
-        ... (10 IDs)
-      }
-    }
+    "sort-packages": true
   },
```

`composer audit` now reports only the pre-existing `psy/psysh` advisory (drush CLI dev dep, local-only — unchanged from yesterday's writeup).

## Why this matters

The fragile state we documented yesterday — "trade several drupal-core CVEs for one twig sandbox-escape vuln" — is now resolved on both sides. Drupal core has up-to-date security fixes AND twig is on a clean release. No more accepted-risk ignores in the project's audit config.

## Verification on dev

- `drush cr` — successful.
- `drush status` reports `Drupal version: 11.3.10`.

## Deploying to live

```bash
git pull
composer install --no-dev    # pull in the new lock
drush updb -y                 # no-op this time but safe to run
drush cr
```

That's all. No config to import (no `drush cim` needed — this is purely a code-level upgrade), no schema changes, no scaffold updates.

## Remaining open advisory (unchanged)

`psy/psysh` medium-severity local privilege escalation via CWD `.psysh.php` auto-load ([CVE-2026-25129](https://github.com/advisories/GHSA-4486-gxhx-5mg7)). PsySH is a drush CLI debugger dependency, not exposed via HTTP. Will pick up a fix when drush ships a newer release.
